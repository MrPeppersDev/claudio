# common-phrases.txt — stock utterances that show up often enough in
# assistant responses that pre-caching them is worthwhile. warm-cache.sh
# feeds each non-blank, non-comment line through the synth pipeline with
# playback disabled, so when the real message uses the phrase it's a
# cache hit and the first-sentence synth cost disappears.
#
# Keep entries to a single sentence. Match ending punctuation to how
# the phrase usually lands in prose (otherwise the hash won't match).
# Cache entries for unused phrases are evicted by the normal mtime LRU,
# so an over-eager list just costs a bit of disk until it's pruned.
